## Help with fees (researched Oct 18, 2026; check the program page before promising anything)
- **Canadian Tire Jumpstart individual child grants**: up to $300 per child per year, paid straight to the program provider. **BBG is already signed up to take Jumpstart grants** (Cody, Oct 2026). The program must run at least 5 weekly sessions (or a camp of 5+ days in a row), and the family applies before the program starts. https://jumpstart.canadiantire.ca/pages/individual-child-grants
- **KidSport Ontario**: up to $250 per child, applied for by the family; for January-February programs the deadline is December 4, 2026. KidSport only covers clubs that belong to their provincial sport body (for boxing, Boxing Ontario). **BBG isn't registered with Boxing Ontario or any other sport body (Cody, Oct 2026), so don't offer KidSport.** If that changes, this line changes. https://kidsportcanada.ca/ontario/
- Never ask a family about their income. Tell them the program exists, how to apply, and that BBG can confirm class dates and fees if the program asks.
